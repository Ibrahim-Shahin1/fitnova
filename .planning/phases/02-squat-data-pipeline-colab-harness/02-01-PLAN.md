## Determinism preconditions (audit list — F12)

For bitwise-identical training-trajectory reproducibility (Task 14's epoch-1 assertion):

1. **`from backend.training.aqa.harness import _envinit` is the FIRST line of Cell 0** (F8 / D13) — sets `CUBLAS_WORKSPACE_CONFIG=:4096:8` before any CUDA context creation.
2. Global seed via `set_global_seed(42)` covers Python `random`, NumPy, torch CPU, torch CUDA (all devices).
3. `torch.backends.cudnn.deterministic = True`, `torch.backends.cudnn.benchmark = False`.
4. `torch.use_deterministic_algorithms(True, warn_only=True)` invoked from `harness/colab.py` import.
5. `DataLoader(num_workers=0)` for the tiny run (Phase 2 only; Phase 3 may bump with `worker_init_fn`).
6. `uniform_sample_indices(generator=g)` takes an explicit `torch.Generator` seeded from the global seed.
7. `spatial_train(...)` takes an explicit `torch.Generator` for random crop.
8. `restore_rng_state(state)` restores all 4 RNGs at resume entry, before any other randomness consumer runs.

This is the post-resume bitwise contract; relax any of these and the bitwise assertion in Task 14 will fail.
</determinism_checklist>

    2. `uniform_sample_indices(num_frames, target=32, jitter=0, *, generator=None) -> torch.Tensor`:
       - `base = torch.round(torch.linspace(0, num_frames - 1, target)).long()`

    3. `decode_clip(path, indices) -> torch.Tensor` — **window-bounded decode per F11 Option A**:
       - First cheap read: use `torchvision.io.read_video_timestamps(path, pts_unit="sec")` to learn `fps` and total frame count without decoding any frames (free).
       - Compute window: `start_pts = float(indices.min()) / fps`, `end_pts = float(indices.max() + 1) / fps`. The `+1` gives the decoder one extra frame of slack on the right edge.
       - Decode the window: `video, _, _ = torchvision.io.read_video(path, start_pts=start_pts, end_pts=end_pts, output_format="TCHW", pts_unit="sec")` — discard audio and info per RESEARCH.md §5 footgun.
       - Re-base indices to the decoded window: `decoded_start_frame = round(start_pts * fps)`; `rebased = (indices - decoded_start_frame).clamp(0, video.shape[0] - 1)`. Use `rebased` to fancy-index.
       - Suppress the packed-B-frame UserWarning with a scoped `warnings.catch_warnings()`.
       - `out = video[rebased]` — fancy-index along the T axis.
       - Return `[T, 3, H, W]` uint8. Assert shape `(target, 3, H, W)` before returning.
       - **Inline `# F11 (RESEARCH §5):` comment** marks the windowed-decode block. Rationale: RESEARCH §5 explicitly warns that reading the full video then indexing risks OOM on long Squat clips (404 frames × 480×600×3 ≈ 350 MB uncompressed); window-bounded decode caps memory at the picked-indices span.

       Rationale for picking F11 Option A over Option B: Option A's added complexity is one extra `read_video_timestamps` call plus an index re-base — trivial. Option B (full read + TODO comment) would leave a known OOM risk in the loader that Phase 3 inherits at higher batch sizes. Option A pays the cost once in Phase 2 and removes the risk permanently.
    4. `spatial_train(clip_tchw, *, crop_size=112, resize_short=128, generator=None) -> torch.Tensor`:
       - Aspect-preserving resize: `H' = round(H * scale)`, `W' = round(W * scale)` where `scale = resize_short / min(H, W)` — using `torchvision.transforms.functional.resize(clip, [H', W'], antialias=True)`.

       - Permute `(T, C, H, W) → (C, T, H, W)`.
       - Return `[3, T, crop_size, crop_size]` float32.
       - **No horizontal flip** (D5).
