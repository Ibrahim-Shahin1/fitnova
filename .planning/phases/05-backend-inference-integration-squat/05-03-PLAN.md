<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> REST `POST /analyze-form-video` | Untrusted multipart video upload (file bytes + `exercise` field) crosses into the server |
| process -> disk (temp file) | The uploaded video is written to a `NamedTemporaryFile` for decoding |
| disk -> process (model load) | `torch.load` deserializes staged `best.pt` at startup |
| handler -> model (read-only) | Per-rep clips are classified by the shared read-only `SquatFormService` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Denial of Service | unbounded `await file.read()` in the upload endpoint | mitigate | `MAX_UPLOAD_BYTES = 100 MB`: HTTP 413 on `Content-Length` before reading, AND chunked read aborting if the running total exceeds the cap. The in-scope HIGH mitigation for the new upload surface (CONCERNS.md unbounded-read HIGH). |
| T-05-08 | Denial of Service | temp file orphaned if `NamedTemporaryFile` throws before assignment | mitigate | `tmp_path = None` before the `with`; `if tmp_path: os.unlink(tmp_path)` in finally (closes the CONCERNS.md NameError/orphan gap — trivially adjacent). |
| T-05-09 | Tampering / Input Validation | `exercise` form field | mitigate | Allowlist: must be `"squat"` (Phase-5 Squat-only) else HTTP 400 (ASVS V5). |
| T-05-11 | Denial of Service | synchronous ~2.8 s torch forward blocking the event loop | mitigate | Inference via `classify_clip_async` -> `run_in_threadpool`; the event loop stays responsive (RESEARCH Pitfall 3). |
| T-05-12 | Spoofing / Access Control | wildcard CORS + no rate limit on the endpoint | accept | DEFERRED per CONTEXT (CORS allowlist + rate limiting are out of Phase-5 scope; not trivially adjacent). Local single-user demo server. |
| T-05-13 | Tampering | `torch.load(best.pt, weights_only=False)` at startup | accept | Developer-produced Phase-4 checkpoints from a trusted Drive path (D-09); not attacker-supplied. Local single-user server. |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages (RESEARCH § Package Legitimacy Audit — torch/torchvision/starlette/opencv already in requirements.txt). No install task -> no slopcheck gate. |
</threat_model>
