<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> WS `/ws/form-session` | Untrusted base64-JPEG frames + JSON control messages stream in per connection |
| per-connection buffer -> model (read-only) | Each session's frame buffer is private; the model is shared read-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-10 | Tampering | malformed base64-JPEG in a WS `frame` causing `cv2.imdecode` to return None | mitigate | `if frame is None: return None` in `add_frame` — drop the bad frame, keep the session alive; never pass None into the model (ASVS V5). Covered by `test_ws_malformed_frame`. |
| T-05-11 | Denial of Service | synchronous ~0.93 s torch forward blocking the event loop per fired rep | mitigate | Live inference via `classify_clip_async` -> `run_in_threadpool`; other connections + endpoints stay responsive (RESEARCH Pitfall 3). |
| T-05-14 | Denial of Service | unbounded frame buffering per connection | mitigate | `deque(maxlen=LIVE_BUFFER_MAX_FRAMES=90)` caps the per-session buffer at ~3 s of frames; old frames are evicted (no unbounded growth). |
| T-05-15 | Information Disclosure | per-connection state leaking across sessions (the old FormAnalyzer concurrency bug) | mitigate | `SquatLiveSession` is constructed fresh per WebSocket; the model is read-only and stateless for inference (Plan 01) — no shared mutable inference state (CONCERNS.md lesson). |
| T-05-12 | Spoofing / Access Control | no auth / no origin check on the WS endpoint | accept | DEFERRED per CONTEXT (auth + CORS hardening out of Phase-5 scope). Local single-user demo server. |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages (RESEARCH § Package Legitimacy Audit). No install task -> no slopcheck gate. |
</threat_model>
