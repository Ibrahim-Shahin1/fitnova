    `segment_reps_by_motion_energy(video_path, min_rep_frames=DEFAULT_MIN_REP_FRAMES, energy_threshold_factor=ENERGY_THRESHOLD_FACTOR) -> list[tuple[int,int]]`:
      1. `cv2.VideoCapture(video_path)`; loop `cap.read()`; per frame `cv2.resize(frame, (64,64))` → `cv2.cvtColor(.., COLOR_BGR2GRAY)` → append float32. Release. (Low-res grayscale = fast; full res not needed for motion energy.)
      2. If fewer than 2 frames decoded → return `[(0, max(n-1, 0))]`.
      3. Per-frame motion energy = `mean(abs(frame[i] - frame[i-1]))`.
      4. Smooth with a boxcar of width SMOOTH_WINDOW (`np.convolve(..., mode="same")`).
      5. `threshold = energy_threshold_factor * mean(smoothed)`; find contiguous regions where smoothed > threshold; merge regions whose inter-region gap < min_rep_frames; each merged region = one rep `(start_frame, end_frame)`, 0-indexed into the full clip.
      6. FALLBACK (ALWAYS return >=1 interval): if no region OR a single region spanning ~the whole clip → return `[(0, total_frames-1)]` and `logger.info("rep_segmenter: no boundaries detected — treating as single rep")` (single-rep Fitness-AQA clip = the simplest correct case, D-03).
      Log the smoothed-energy mean/peak and detected interval count (so Plan 02's real-clip validation can inspect the signal).

    `class LiveWindowTrigger` (per-connection helper used by Plan 03's SquatLiveSession; keeps trigger arithmetic unit-testable independent of WebSocket/JPEG): `__init__` → `self._frames_since_last = 0`. `should_fire(self, buffer_len: int) -> bool`: `self._frames_since_last += 1`; if `buffer_len >= LIVE_REP_WINDOW_FRAMES and self._frames_since_last >= LIVE_MIN_GAP_FRAMES`: set `self._frames_since_last = 0` and return True; else return False.
