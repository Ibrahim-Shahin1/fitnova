<objective>
Train a paper-faithful supervised R(2+1)D-18 baseline detector for Squat KIE and KFE on the labeled Squat set, and report F1 per error on the official Squat test split with the per-error decision threshold tuned independently on the official val split. This phase consumes the Phase 2 data pipeline and resumable Colab harness verbatim and adds three new code artifacts (a pure-function metrics library `eval/metrics.py`, a full trainer `harness/supervised_train.py`, and the driving Colab notebook `notebooks/03_squat_supervised_baseline.py`) plus pytest coverage for both new modules. The end-of-phase deliverable is six supervisor-grade figures + a `results.pkl` artifact + the `best.pt` checkpoint on Drive that Phase 4 will fork for Motion-Disentangling fine-tuning.

Purpose: ROADMAP criterion "in the range of the paper's supervised baseline" is the empirical anchor for the entire form-correction rebuild. Without numbers from this phase, every downstream phase (MD-SSL, backend inference, OHP, ensemble) lacks a reference point. The paper's Table 2 reports KIE=0.297 / KFE=0.818 for the frozen-backbone Kinetics row and KIE=0.419 / KFE=0.834 for the end-to-end MD row; D1 locks end-to-end fine-tune, so Phase 3 targets the MD row (RESEARCH §1, §13 question 1). Either row demonstrates "in range" — the planner declares the MD row the success-criterion target.

Output: 6 new `.py` source files under `backend/training/aqa/{eval, harness, notebooks}/`, 6 PNG figures + 1 pickle results artifact + 1 SUMMARY.md under `.planning/phases/03-squat-supervised-baseline/figures/`, a trained `best.pt` checkpoint at `My Drive/FitNova/checkpoints/phase03/r2plus1d18_squat_supervised_v1/best.pt`, and ROADMAP/REQUIREMENTS/STATE flips marking SQUAT-03 complete (orchestrator follow-up).

Execution is INTERACTIVE per [[feedback_interactive_execution]]: each task hands the user exactly one runnable unit (a notebook cell, a `pytest` invocation, or a shell line) and stops until output is pasted back. The first-epoch timing cell (Task 10) is a hard gate: the user pastes back per-batch wall-time before the full training run is authorized; if `estimated_total_h > 8`, the plan offers a documented fallback (drop to 15 epochs or enable AMP overriding RESEARCH §11).
</objective>
